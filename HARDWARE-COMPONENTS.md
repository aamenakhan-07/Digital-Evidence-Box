Hardware Components – Digital Evidence Box

1. Introduction

The Digital Evidence Box uses electronic and sensing components to provide secure evidence storage and monitoring.

2. Proposed Hardware Components

Component| Purpose
ESP32| Main controller for system operations
Fingerprint Sensor| Authorised user authentication
Weight Sensor| Detecting weight changes inside the box
Camera Module| Capturing user photographs
GPS Module| Tracking evidence box location
Electronic Lock| Controlling box access
Alarm/Buzzer| Alerting during forceful access attempts
RTC Module| Maintaining date and time
MicroSD Card Module| Storing backup activity records
Control Panel| Managing multiple evidence boxes

3. Hardware Functioning

- Fingerprint authentication verifies authorised users.
- The electronic lock controls access to the evidence box.
- Sensors monitor changes in evidence weight.
- The camera captures access-related photographs.
- The alarm alerts users about forceful access attempts.
- Date and time information is recorded for important activities.
- SD card storage provides additional data backup.

4. Centralised System

A single control panel is designed to manage multiple evidence boxes. Each box will have its own activity records, while all updates will be available through one centralised software dashboard.

5. Important Note

The components and functions listed above describe the proposed system architecture. Individual components and features are subject to implementation and testing.
