System Architecture – Digital Evidence Box

1. System Overview

The Digital Evidence Box is designed around three main units:

1. Evidence Box
2. Central Control Panel
3. Software Dashboard

These units work together to provide centralised evidence security and monitoring.

2. System Architecture

A. Evidence Box

Each evidence box is designed to contain:

- Fingerprint authentication system
- Electronic locking mechanism
- Camera module
- Weight monitoring sensor
- Forceful access detection
- Alarm system
- Location tracking module

B. Central Control Panel

- Coordinates multiple evidence boxes.
- Manages communication between connected boxes and software.
- Collects activity updates.

C. Software Dashboard

- Displays authorised officer information.
- Shows opening and closing records.
- Displays photographs and activity logs.
- Monitors weight changes.
- Displays security alerts.
- Monitors box locations.
- Provides authorised emergency PIN access.

3. Data Flow

1. Officer provides fingerprint authentication.
2. The system verifies authorised access.
3. The box records opening activity.
4. Sensors monitor evidence-related changes.
5. Activity information is communicated to the central system.
6. The software dashboard displays the updates.
7. Backup records are maintained on an SD card.

4. Security Mechanism

The proposed system combines biometric authentication, electronic locking, forceful access detection, alarm alerts, activity logging, and emergency access control.

5. Scalability

The architecture is designed to support multiple evidence boxes managed through one central control panel and a unified software dashboard.
