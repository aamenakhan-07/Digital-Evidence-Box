Project Workflow – Digital Evidence Box

1. System Startup

The evidence box and central control panel are powered on and connected to the monitoring software.

2. Officer Authentication

- An authorised officer places their registered finger on the fingerprint scanner.
- The system verifies the fingerprint.
- The officer's registered profile is identified.
- Successful authentication allows the box to unlock.

3. Box Opening

- Opening date and time are recorded.
- The camera captures the officer's photograph.
- Officer details and access information are updated in the software.

4. Evidence Monitoring

- The weight sensor monitors changes inside the box.
- Adding evidence generates a weight increase update.
- Removing evidence generates a weight decrease update.
- The software displays the detected changes.

5. Security Monitoring

- The system monitors forceful access attempts.
- An alarm is activated when such an attempt is detected.
- The box remains locked.
- The incident date and time are recorded.

6. Box Closing

- Closing date and time are recorded.
- The photograph of the authorised person closing the box is captured.
- The activity record is updated in the dashboard.

7. Centralised Monitoring

- Multiple evidence boxes are managed through one control panel.
- Their individual records are displayed in one software dashboard.
- Location information and security updates are monitored centrally.

8. Backup and Emergency Access

- Temporary activity records are backed up on an SD card.
- An authorised PIN-based emergency access mechanism is provided through the software for technical glitches.

9. Expected Result

The proposed workflow aims to provide secure access, automated activity records, evidence weight monitoring, and centralised forensic evidence management.
