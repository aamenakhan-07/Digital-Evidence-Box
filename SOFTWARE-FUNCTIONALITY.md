Software Functionality – Digital Evidence Box

1. Introduction

The software dashboard is designed to provide centralised monitoring and management of multiple digital evidence boxes.

2. Authorised Officer Management

- Stores authorised team members' profiles.
- Maintains registered fingerprint information.
- Displays officer identification details after successful authentication.

3. Access Monitoring

- Records box opening date and time.
- Captures the photograph of the officer opening the box.
- Records the officer's details and access location.
- Records box closing date and time.
- Captures the photograph of the person closing the box.

4. Evidence Weight Monitoring

- Detects weight increases when evidence is added.
- Detects weight decreases when evidence is removed.
- Updates the software dashboard with weight-related changes.

5. Security Alerts

- Detects forceful access attempts.
- Activates an alarm.
- Records the date and time of the incident.
- Prevents unauthorised box opening.

6. Location Monitoring

- Tracks the location of connected evidence boxes.
- Displays location updates through the software.

7. Multiple Box Management

- Monitors multiple evidence boxes through one centralised dashboard.
- Maintains individual records for each box.

8. Emergency Access

- Provides authorised PIN-based access through the software in case of technical issues.

9. Data Backup

- Stores temporary backup records on an SD card.
- Helps maintain activity records during software-related issues.

10. Development Status

The software functionality described in this document represents the proposed system design. Features will be implemented and validated as hardware and software integration progresses.
