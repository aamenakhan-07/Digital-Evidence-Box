Project Overview – Digital Evidence Box

1. Introduction

Digital Evidence Box is a smart forensic evidence storage and monitoring system designed to improve evidence security, access control, and chain-of-custody management.

2. Problem Statement

Traditional evidence storage systems may depend heavily on manual entry and monitoring. This can create challenges in tracking access, maintaining records, and ensuring accountability.

3. Proposed Solution

The proposed system combines biometric authentication, automated activity logging, weight monitoring, photo capture, location tracking, and centralised software management.

4. Main Components

- Biometric fingerprint scanner
- Evidence storage box
- Central control panel
- Weight sensor
- Camera module
- Location tracking module
- Alarm system
- SD card storage
- Software dashboard

5. Expected Outcome

The project aims to provide a more secure, transparent, and organised approach to forensic evidence management.
