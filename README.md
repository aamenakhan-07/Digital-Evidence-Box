🔐 Digital Evidence Box

Smart Forensic Evidence Security and Monitoring System

Researcher: Aamena Jawwad Ahmed Khan

---

📌 About the Project

Digital Evidence Box is a smart forensic evidence storage and security system designed to protect digital and physical evidence while maintaining transparency, accountability, and proper chain-of-custody records.

The system aims to combine biometric authentication, real-time monitoring, automated record keeping, weight detection, photo capture, location tracking, and centralised software management.

Its main objective is to minimise unauthorised access, improve evidence security, and maintain reliable records of every evidence-related activity.

🎯 Key Features

1. Biometric Authentication

- Fingerprint-based access control.
- Pre-registered authorised team members.
- Officer identification through stored profiles.

2. Automated Activity Logging

- Records box opening and closing dates and times.
- Captures photographs of authorised users.
- Maintains officer identification details.

3. Weight Monitoring

- Detects weight increases when evidence is added.
- Detects weight decreases when evidence is removed.
- Updates evidence-related activity in the software.

4. Forceful Access Detection

- Detects unauthorised forceful opening attempts.
- Activates an alarm.
- Records the date and time of the event.
- Keeps the box locked.

5. Location Tracking

- Continuous location monitoring of evidence boxes.
- Location information available through the centralised software.

6. Centralised Monitoring

- One control panel manages multiple evidence boxes.
- All connected boxes can be monitored through one software dashboard.
- Individual activity records for each box.

7. Data Backup

- Temporary backup records stored on an SD card.
- Helps preserve activity records during software-related issues.

8. Emergency Access

- Authorised PIN-based emergency access through the software in case of technical glitches.

⚙️ System Architecture

The proposed system consists of three major components:

1. Evidence Box: Physical storage unit with biometric authentication and monitoring sensors.
2. Central Control Panel: Manages and coordinates multiple evidence boxes.
3. Software Dashboard: Displays authorised user information, activity logs, alerts, weight changes, and location updates.

🔄 Working Process

1. An authorised officer scans their registered fingerprint.
2. The system verifies the officer's identity.
3. The evidence box unlocks after successful authentication.
4. Opening date, time, and officer details are recorded.
5. The camera captures the authorised user's photograph.
6. Weight sensors monitor evidence being added or removed.
7. Closing activity is recorded with date, time, and user photograph.
8. All connected box records are managed through the centralised software.

💡 Innovation

The project focuses on combining biometric security, evidence activity monitoring, automated documentation, and centralised management into a single forensic evidence management system.

It aims to strengthen evidence accountability and reduce dependency on manual record keeping.
